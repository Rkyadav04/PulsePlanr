# 🚀 PulsePlanr – Smart Productivity Planner

PulsePlanr is a **task and productivity management web application** designed to help users organize their daily work, track progress, and stay productive.
It allows users to create tasks, manage schedules, and monitor completion status through a simple and clean interface.

This project demonstrates **full-stack web development using Django**, including backend logic, database integration, and frontend UI.

---

# 📌 Features

✔ Create, update, and delete tasks
✔ Organize tasks by priority and date
✔ Track completed and pending tasks
✔ Clean and responsive user interface
✔ Search and filter functionality
✔ Backend powered by Django framework

# ⚙️ Installation & Setup

## 1️⃣ Clone the repository

```
git clone https://github.com/YOUR_USERNAME/PulsePlanr.git
```

---

## 2️⃣ Navigate to the project

```
cd PulsePlanr
```

---

## 3️⃣ Create a virtual environment

```
python -m venv venv
```

---

## 4️⃣ Activate the virtual environment

### Windows

```
venv\Scripts\activate
```

### Mac/Linux

```
source venv/bin/activate
```

---

## 5️⃣ Install dependencies

```
pip install -r requirements.txt
```

---

## 6️⃣ Apply migrations

```
python manage.py migrate
```

---

## 7️⃣ Run the development server

```
python manage.py runserver
```

---

## 8️⃣ Open in browser

```
http://127.0.0.1:8000/
```
